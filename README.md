# empytree / система личного знака

Утверждённая система личного знака empytree. Пологое промежуточное вдавливание боков, неровный стык нот и оптическая версия для 16 px. Рабочий сайт пока не переключён.

Основной знак: `flat` + `open` + ровные бока. Шесть выражений × четыре состояния боков дают 24 сочетания по умолчанию; закрытая рамка расширяет набор до 48. Три оптических размера. Залом сверху остаётся крупным вариантом. Развитие независимых музыкальных верхов и пауз записано в документе как будущий план.

Версия правил 1.3: окончательно утверждены пологая промежуточная вмятина `from-inset` и неровный стык `character`. Мелкая вмятина исключена. Только в micro головки чуть уменьшены для зазора у левой стороны. Политика экспорта — в `tools/identity-config.mjs`; другие профили в сравнениях являются историческими.

Будущий план даёт 144 комбинации при одной рамке, 288 с открытой/закрытой рамкой и 432 для display с дополнительным заломом. Эти варианты ещё не реализованы как полная музыкальная матрица.

Политика прав ещё не выбрана. Публичный просмотр и возможность форка на GitHub сами по себе не означают разрешения использовать персональный знак как чужой бренд. Проект пока не объявляется open source; предложения по лицензированию описаны отдельно и не заменяют принятую лицензию.

Для пересборки: `npm install`, `npm run build`, `npm run check`. Исследовательские образцы: `npm run research:examples`; проверка документации и расчёт вариантов: `npm run audit:docs`. Node/Sharp нужны только разработчику; сайт получает готовые файлы. При переносе в PHP-репозиторий Node-инструменты можно оставить отдельным вложенным инструментом. Сначала подключить и проверить локально, затем включать существующий релизный процесс владельца.
