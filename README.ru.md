Утверждённая система личного знака empytree. Пологое промежуточное вдавливание боков, неровный стык нот и оптическая версия для 16 px. На сайте внедрена версия 0.1.0; [запись внедрения](docs/adoptions/0.1.0.md) содержит публичные подтверждения. Следующий кандидат — 0.2.0 с полным генератором и отбором micro.

Основной знак: `flat` + `open` + ровные бока. Шесть выражений × четыре состояния боков дают 24 сочетания по умолчанию; закрытая рамка расширяет набор до 48. Три оптических размера. Залом сверху остаётся крупным вариантом. Независимые музыкальные верхи и паузы реализованы в следующем каталоге `public/brand/v2/`.

Версия правил 1.3: окончательно утверждены пологая промежуточная вмятина `from-inset` и неровный стык `character`. Мелкая вмятина исключена. Только в micro головки чуть уменьшены для зазора у левой стороны. Политика экспорта — в `tools/identity-config.mjs`; другие профили в сравнениях являются историческими.

Полная матрица реализована: 144 сочетания при одной рамке, 288 с открытой/закрытой и 432 для display с заломом. Micro-политика допускает 40 из 288, включая 20 открытых вариантов по умолчанию; 248 исключены. Это не сертификация читаемости во всех браузерах.

Политика прав ещё не выбрана. Публичный просмотр и возможность форка на GitHub сами по себе не означают разрешения использовать персональный знак как чужой бренд. Проект пока не объявляется open source; предложения по лицензированию описаны отдельно и не заменяют принятую лицензию.

Для пересборки: `npm ci`, `npm run build`, `npm run check`. Исследовательские образцы: `npm run research:examples`; проверка документации и расчёт вариантов: `npm run audit:docs`. Node/Sharp нужны только разработчику; сайт получает готовые файлы. При переносе в PHP-репозиторий Node-инструменты можно оставить отдельным вложенным инструментом. Сначала подключить и проверить локально, затем включать существующий релизный процесс владельца.
