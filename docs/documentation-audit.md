25 октября 2026. Текущий исходный пакет — **0.3.0**, конструкция 1.4, micro-политика 2. Последнее подтверждённое публичное внедрение — **0.2.1**. Внедрение подтверждено публичными страницами, no-JS, хлебными крошками и 581 контрольной суммой. [Запись](adoptions/0.2.1.md).

## Текущий аудит

- Оба README начинаются актуальной картинкой, затем описывают действующую систему, а не первый пул 24.
- Обзорные листы содержат четыре крупных заметно разных пары глаз/ртов, девять ртов, рамки, бока и оптику. Есть EN/RU версии.
- `pixel-check` показывает двенадцать разных лиц и настоящие слои ICO 16/32/48, в актуальных оптических рисунках: micro в 16, compact в 32/48.
- Новый `build-docs.mjs` строит текущие сводки из того же генератора и ICO. Старый `build.mjs` больше не перезаписывает их макетами первой версии.
- Текущие спецификации и инструкция подключения описывают 288 сочетаний, общий открытый default 144, независимый серверный Home и no-JS. Автоматических micro-запретов нет.
- Исторические сравнения подписаны и перечислены отдельно; датированные поисковые образцы сохранены как материалы исследования.
- Удалены текущие утверждения «генератор в планах», «репозиторий не опубликован», «0.2.1 ещё не внедрена». Первоначальные состояния в журнале и changelog имеют исторический контекст.
- README и правила различают опубликованный исходный пакет и последующие правки документации. Используемый сайтом SHA не меняется от обновления обложки.

Машинный результат проверки локальных ссылок, конфигурации, количеств и записи текущего внедрения — [documentation-check.json](research/documentation-check.json). `npm run verify` пересобирает графику и выполняет проверки поведения. Рендеры сводок дополнительно просматриваются визуально; Markdown может масштабировать их, поэтому проверка настоящих пикселей проводится на исходном изображении.

## Проверка 0.3.0

- Две явно заданные непрозрачные палитры; micro-рамка 16 × 16, лицо сохраняет пиксельные координаты.
- Проверены все 576 ICO и все десять слоёв каждого: размеры, полная непрозрачность, совпадение с прямым векторным растром нужной оптики.
- Проверены тема при загрузке, событие change, сохранение лица/мешка, старый addListener и недоступный matchMedia.
- Контуры всех рамок проверены на расширенном поле: ничего не выходит за границы.
- `npm run verify`: 27 тестов. Новый лист двух палитр просмотрен как PNG. Реальное Apple-устройство не тестировалось; браузерный выбор слоя не подменяется тестом файла.

## Что сохраняется из прежнего аудита

Выбранный `from-inset` не называется кандидатом; наклоны идут по большей части стороны после коротких прямых у углов. В старых таблицах координаты базовые; production 1.4 строит контур полностью внутри расширенного поля. `character` — окончательный выбор, не дефект для исправления. Независимость параметров не означает независимые случайные броски: favicon выбирается из перемешанного пула сочетаний.

Исследование аналогий не выдаётся за выполненный обратный поиск по загруженной картинке или поиск товарных знаков. Правовой обзор не превращается в лицензию или международную регистрацию. В этой редакции не проводилось новое юридическое или визуальное интернет-исследование: исходные датированные результаты сохранены с их границами.
