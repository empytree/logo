# Цвет линий и прозрачность

[English](en/colors.md) · [Размещение и плотность](themes-and-density.md) · [Генератор](../examples/generator.html)

Принято автором 25 октября 2026 для **0.3.1**. Форма и цвет описываются разными правилами: геометрия узнаваема и повторяема, цвет может отвечать конкретной поверхности и творческой задаче.

| Назначение | Рекомендуемый цвет линий | Фон файла |
| --- | --- | --- |
| На светлой поверхности (`light`) | `#20211f`, тёмный | Прозрачный |
| На тёмной поверхности (`dark`) | `#f5f4ef`, светлый | Прозрачный |

**Это рекомендации, а не строгие фирменные константы.** Допустим другой явный цвет при творческой необходимости: например, в композиции, иллюстрации или на иной поверхности. Выбирающий цвет отвечает за контраст и читаемость в фактическом размере. Особенно внимательно проверять 16px; смена цвета не должна маскировать тонкие части, паузы и вмятины.

Прозрачность означает отсутствие подложки во всех рабочих SVG/PNG и во всех слоях ICO. У сглаженных краёв есть промежуточная alpha; пиксели вне линий полностью прозрачны. Примерные поверхности `#f5f4ef` и `#20211f` в сводных листах и HTML-просмотре не входят в скачиваемые изображения.

Творческая смена цвета не меняет утверждённые неровные стыки, пологие вмятины, оптические рисунки или число выражений. Дополнительные цвета не перемешиваются случайно на сайте: штатный пакет содержит два рекомендуемых начертания. В текущем API переопределение — явный непрозрачный hex RGB, а не случайная или неявно унаследованная окраска.

```sh
npm run generate -- --eyes mixed --mouth rest2 --theme dark --size 48 --output .local/mark.svg
npm run generate -- --eyes mixed --mouth rest2 --theme light --color '#804020' --size 48 --output .local/mark-custom.svg
```

```js
renderMark({eyes:'mixed', mouth:'rest2', optical:'compact', theme:'light', color:'#804020'});
```

`theme` обозначает предполагаемую поверхность; `color` явно переопределяет рекомендуемый цвет линий. Фон остаётся прозрачным. Для производных композиций допустимо свободнее работать с цветом при сохранении узнаваемости и ясных условий размещения; это не отдельное разрешение на использование личного знака как чужого бренда.
