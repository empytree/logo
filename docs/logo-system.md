# Конструкция и характер знака

[English](en/logo-system.md) · [README](../README.ru.md) · [Генератор](generator.md) · [Подключение](en/usage.md)

Текущая система — **0.3.1**, конструкция **1.5**, политика micro **2**. Версия внедрена на empytree.com; подтверждённый исходный SHA пакета фиксируется отдельно от позднейших правок документации. [Правила двух палитр и плотности](themes-and-density.md).

## Характер

Тихая музыка из помятой коробки. В исходном верхе головки, штили, угловые флажки и отдельные короткие штрихи слева напоминают одновременно ноты и стрелки «этой стороной вверх». Меняющийся рот и квадратная коробка сохраняют семейство при смене пары глаз.

Стык головки и штиля намеренно неровный. Сохранять повторяемую ступеньку; не сглаживать автоматически, не усиливать случайно и не превращать в зазор. Способность удерживать взгляд — проектная гипотеза. Пологая промежуточная вмятина начинается после коротких прямых у углов, остальная часть стороны идёт к одному внутреннему углу. Для коробки не нужны текстура, перспектива, лента или тени.

## Части и фиксированные решения

| Параметр | Текущие значения |
| --- | --- |
| `eyes` | `arrows`, `beam`, `separate`, `mixed` |
| `mouth` | `flat`, `rise`, `fall`, `corner-left`, `corner-right`, `down`, `rest8`, `rest4`, `rest2` |
| `dent` | `none`, `left`, `right`, `both` |
| `frame` | `open`, `closed`, `crease` — последняя только display |

Основной знак — `arrows / flat / open / none`. Единственный рабочий профиль — `dentProfile='from-inset'`, единственный стык — `joint='character'`. Они не перемешиваются. Аккуратные стыки и другие вмятины сохранены как [исторические сравнения](brand/README.md), а не рабочие варианты.

`mixed` — короткая вязка левой ноты и отдельный флажок правой, не ещё одна связанная пара. Половинная пауза стоит над короткой опорной линией. Эти композиции не претендуют на полноценную исполняемую партитуру.

Источник истины — `tools/identity-config.mjs`, `tools/geometry.mjs`, `tools/system.mjs`. Текущий API — `renderMark({eyes,mouth,frame,dent,optical})`. Старый `mark({family: ...})` оставлен для совместимости и исторических этюдов.

## Геометрия

Исходное display-лицо построено на сетке 64 × 64. Таблицы ниже задают базовые координаты до переноса на полное поле 0.3.0; micro-рамка имеет новые координаты из [правил размещения](themes-and-density.md):

| Элемент | Конструкция |
| --- | --- |
| Рамка | Осевая `(4,4)…(60,60)`, толщина 2; прямые углы |
| Открытый верх | Разрыв x=24…40 |
| Головки | Центры `(22,35)`, `(40,35)`; радиусы 4.75 × 3.1; поворот −12° |
| Штили | x=26 и 44, y=18…35; толщина 2.5 |
| Правый флажок | `(x,18) → (x+6,24)` |
| Отдельный левый штрих | `(x−8.5,23.5) → (x−6,21)` |
| Прямой рот | x=18…46; середина y=47.5; толщина 2.5 |

Острые miter-стыки выступают за вершины осевых линий. Другие пары глаз имеют собственное фиксированное оптическое размещение; смена рта или боков не двигает глаза.

Геометрические рты используют постоянное поле каждой сетки:

| Сетка | Слева/справа | Сверху/снизу | Толщина |
| --- | --- | --- | --- |
| Display | 18 / 46 | 45 / 50 | 2.5 |
| Compact | 8 / 24 | 23 / 26 | 1.75 |
| Micro | 4 / 12 | 11 / 13 | 1 |

`rise` идёт снизу слева вверх направо, `fall` — наоборот. `corner-left` заполняет треугольник верх-лево/верх-право/низ-лево, `corner-right` — верх-лево/верх-право/низ-право. `down` — центральный треугольник вершиной вниз, с отступом 4/2/1 единицы для display/compact/micro; нижняя вершина y=51/26.5/13. Паузы нарисованы отдельными контурами в `system.mjs`, не символами шрифта. Не поворачивать и не зеркалить весь знак, не вводить свободные случайные деформации.

| Сетка | Левая вмятина | Правая вмятина |
| --- | --- | --- |
| 64 | `(4,12) → (8,32) → (4,52)` | `(60,12) → (56,32) → (60,52)` |
| 32 | `(1.75,5.75) → (3.75,16) → (1.75,26.25)` | `(30.25,5.75) → (28.25,16) → (30.25,26.25)` |
| 16 | `(1.5,3.5) → (2.75,8) → (1.5,12.5)` | `(14.5,3.5) → (13.25,8) → (14.5,12.5)` |

Display-залом сверху: `(47,4) → (50,6) → (53,4)`. В текущем API малый запрос `crease` вызывает ошибку; подмены другой рамкой нет.

## Оптические рисунки и цвет

Micro применяется для 16–20 px, compact — 21–63, display — от 64. Сетки — 16, 32 и 64. Для размера меньше 16 отдельного рисунка нет. Micro сохраняет точку крепления головок и масштабирует их на 0.88 × 0.96: ширина 4 → 3.52, высота 2 → 1.92. Смена вмятин не меняет головки дополнительно.

Каждый ICO содержит 16/20/24/32/40/48/64/96/128/256 физических px. Оптика выбирается по физическому размеру слоя: micro до 20, compact до 63, display от 64. Поэтому Retina получает более подробный рисунок того же выражения. [Сравнение](brand/themes-and-density.png).

Рабочие SVG/PNG/ICO используют режим размещения `light` или `dark` и явно заданный цвет линий с прозрачным фоном. Коробка занимает полное поле. Обязательного охранного отступа внутри файла или снаружи нет; соседние элементы разделяются компоновкой. Micro сохраняет координаты глаз/рта и расширяет только рамку, compact/display переносятся на полное поле. Точные параметры — в [спецификации палитр и границ](themes-and-density.md).

## Разнообразие и утверждение

Матрица даёт 144 выражения при одной рамке, 288 открытых/закрытых малых и 432 display с третьей рамкой. Оптика, плотности, цвета и форматы не увеличивают число выражений.

**Автор разрешил все 288 поддерживаемых сочетаний 16 px.** Четвертные паузы, малые зазоры и совпадения пороговых растров допустимы. Измерения при трёх плотностях справочные и не запрещают варианты. Прежний отбор 40 относится к истории разработки.

Общий selector по умолчанию использует 144 открытых. На сайте включены обе рамки — 288. Для favicon работает проверяемый перемешанный мешок; компактный знак крошек независимо выбирается сервером и доступен без JavaScript.
