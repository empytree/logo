Правила **0.3.1**, конструкция **1.5**, приняты 25 октября 2026 года. Это новый исходный пакет; последнее подтверждённое публичное внедрение пока остаётся [0.3.0](adoptions/0.3.0.md). Новый выпуск не считается внедрённым до проверки сайта.

## Условия размещения

У каждого рабочего знака известен фон размещения, а само изображение прозрачно. Рекомендуемые цвета линий сохраняются; фон страницы просвечивает между линиями и за вмятинами. Подложка в SVG/PNG/ICO не запекается.

| `theme` | Рекомендуемый цвет линий | Условия размещения |
| --- | --- | --- |
| `light` | `#20211f` | Светлая поверхность |
| `dark` | `#f5f4ef` | Тёмная поверхность |

Это рекомендуемые исходные значения, а не строгие фирменные константы. Цвет линий может меняться при творческой необходимости и других условиях размещения: выбрать явный цвет, проверить контраст на реальной поверхности и различимость в фактическом размере, особенно 16 px. Не менять форму или характер стыка ради цвета. Перевёрстка палитры не добавляет выражений лица и не расширяет стандартный случайный пул.

Рабочий API принимает `renderMark({theme:'light',color:'#804020'})`; CLI — `--theme light --color '#804020'`. Явный цвет задаётся непрозрачным hex RGB; `theme` указывает предполагаемый тип поверхности. HTML-генератор и штатный набор сайта используют рекомендованные значения по умолчанию. Бесконтрольное наследование цвета через произвольный текст не считается заданными условиями размещения. В хлебных крошках известна тёмная шапка: выбирается `dark`, независимо от системной темы посетителя. Примеры поверхностей `#f5f4ef`/`#20211f` служат просмотру; их нет в скачиваемом знаке.

Коробка занимает полную сторону холста: 16 × 16 вместо прежних 14 × 14 для микроиконки. Дополнительного обязательного поля внутри файла и обязательного внешнего охранного поля нет. Компоновка страницы может добавлять расстояние до соседних элементов. Контур полностью вписан: острые стыки у вмятин не обрезаются за границей.

Micro сохраняет исходные координаты глаз и рта и уменьшение головок 0.88 × 0.96. Расширяется только рамка: оси прямых боков x=0.5/15.5, верх и низ имеют толщину 1; левая вмятина `(0.5,3.5) → (1.75,8) → (0.5,12.5)`, правая зеркальна. Это сохраняет привязку штилей к пикселям. Растягивание всего старого 14-пиксельного квадрата на 16 создавало бы дробные координаты и размывало ноты.

Для compact исходное поле `[1,31]` переносится на `[0,32]`: `scale(32/30) translate(-1,-1)`. Для display `[3,61]` переносится на `[0,64]`: `scale(64/58) translate(-3,-3)`. Рамка строится замкнутыми заполненными контурами; микровыступы miter у начала наклона ограничены границами поля при построении, а не скрываются обрезкой готовой картинки. Внутренний рисунок сохраняет неровные стыки и выбранный профиль `from-inset`.

`presentation.mjs` задаёт палитры, геометрию рамки и размеры. `theme:null` в низкоуровневом `wrap()` служит только маскам измерений и этюдам на известном фоне; CLI, браузерный генератор и пакеты сайта экспортируют прозрачные изображения с явно заданным цветом линий. `public/brand/v1` сохраняет историческую конструкцию.

## Полный набор разрешений в каждом ICO

| Физические px | Оптический рисунок |
| --- | --- |
| 16, 20 | micro |
| 24, 32, 40, 48 | compact |
| 64, 96, 128, 256 | display |

Каждый из **576 ICO** содержит все десять слоёв. Это 288 выражений × 2 палитры; разрешения не добавляют новых выражений. Каждый слой растеризуется прямо из соответствующего векторного рисунка, без увеличения PNG 16 px. Формат ICO обозначает 256 значением 0 в однобайтовых полях размера.

Для условного значка 16 CSS px при 1×/1.25×/1.5×/2×/2.5×/3×/4× доступны 16/20/24/32/40/48/64 физических px. Выбор делает браузер: сайт сообщает `sizes`, но не может гарантировать конкретный слой в каждом интерфейсе браузера. При повышенной плотности разрешён более подробный compact/display, сохраняя то же выражение. Это намеренно заменяет правило 0.2.1, где все три слоя строились из micro. Измерения micro при 1×/2×/3× остаются справочными измерениями одного рисунка; они не описывают каждый текущий слой ICO.

SVG остаётся вектором. Для inline-знака подходящий оптический рисунок выбирают по размеру размещения; браузер сам растеризует его с плотностью экрана. Размер области ссылки, доступное имя и фокус не зависят от числа пикселей в файле. Apple touch icon — отдельный стабильный PNG 180 px; он не переключается вслед за вкладкой.

## Определение темы на сайте

1. При загрузке selector выбирает выражение из прежнего проверяемого sessionStorage-мешка. Сайт включает обе рамки — 288; общий default — 144 открытых.
2. `matchMedia('(prefers-color-scheme: dark)')` определяет предпочтение. Загружается `${id}.ico` для light или `${id}-dark.ico` для dark.
3. Событие `change` меняет только URL палитры. Выражение, остаток мешка и следующее случайное значение остаются прежними. Таймера и опроса нет.
4. При отсутствии API или ошибке остаётся light. Без JavaScript/при явном no-JS сохраняется канонический светлый `favicon.ico`, также со всеми десятью слоями. Неизвестная/пустая группа параметров сохраняет fallback.

Предпочтение цветовой схемы не сообщает точный цвет панели вкладок или пользовательского оформления браузера. Прозрачный знак требует выбора цвета под фактическую поверхность. При недоступном определении темы светлый fallback означает тёмные линии; его контраст на произвольной тёмной панели не гарантируется. Обновление закешированных значков в закладках зависит от браузера; обещание немедленного переключения всех сохранённых копий не даётся.

Пакет схемы **5** содержит 576 ICO, 576 compact SVG, два канонических ICO, PNG 96/180, selector и manifest: **1158 SHA-256 entries + `logo-source.json`**. Поля `ico`/`icoDark` и `svg`/`svgDark` сопоставлены по одному ID; provenance фиксирует палитры, размеры и оптику слоёв. Нельзя изменять файлы по уже опубликованному версионному URL.

Источники механизма: [MDN: link и несколько размеров ICO](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/link), [Apple: изображения для Retina](https://developer.apple.com/library/archive/documentation/NetworkingInternet/Conceptual/SafariImageDeliveryBestPractices/ServingImagestoRetinaDisplays/ServingImagestoRetinaDisplays.html), [MDN: matchMedia](https://developer.mozilla.org/en-US/docs/Web/API/Window/matchMedia), [событие change](https://developer.mozilla.org/en-US/docs/Web/API/MediaQueryList/change_event).
