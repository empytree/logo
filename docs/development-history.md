# История решений

Зафиксировано 24 октября 2026. Это ретроспективный журнал разработки в диалоге, а не утверждение, что каждый этап уже был отдельным Git-коммитом. Коммиты при переносе создаются с фактическими датами; промежуточные состояния не выдаются за существовавшие публичные релизы.

| Этап | Решение |
| --- | --- |
| Исходный бриф | Музыка из помятой коробки, ноты-глаза/стрелки, геометрический рот, квадрат с разрывом |
| Первая система | Шесть ртов, открытая/закрытая рамка, отдельные micro/compact/display геометрии |
| Вариативность боков | Ровные, левая, правая и две вмятины; одна конструкция на всю систему |
| Исследование | Сравнение локальных, пологих и промежуточных вмятин; отдельный этюд аккуратного стыка |
| Утверждение стыка | Неровный стык сохранён окончательно как авторская особенность |
| Micro | Только головки уменьшены на 0.48 px по ширине и 0.08 px по высоте для зазора у левого бока |
| Утверждение профиля | Выбрана пологая промежуточная вмятина `from-inset` |
| Проверка и исследование | Аудит документации, три визуальных образца для поиска аналогий, расчёт будущих 144/288/432 параметрических сочетаний |
| Разделение проектов | Целевой публичный репозиторий — `empytree/logo`; сайт — самостоятельный потребитель версии ресурсов |

Подробности геометрии и границы исследования находятся в [спецификации](logo-system.md) и [исследовании аналогий](research/image-analogies.md). Отдельного внешнего внедрения этот журнал не утверждает.

## Development summary

The session moved from the author's sketch to controlled expressions, optical sizes, side-state diversity and comparative studies. The author accepted the irregular joint and the intermediate shallow dent. Micro heads were reduced while keeping shafts and the larger drawings unchanged. The public repository records this history and provides a source for versioned downstream adoption. It does not imply that the website has already adopted a release.
