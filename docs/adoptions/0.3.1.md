The owner confirmed rollout. Independent public HTTP checks verified **all 1158 resource hashes**, the source SHA, the ten resolutions in every delivered ICO, and home/jugbeat with and without explicit `nojs=1`. Because the files match the tested source package, its transparent SVG/PNG/ICO exports are delivered unchanged. Normal heads enable both frames; explicit no-JS omits the selector. Jugbeat returns a named home link with decorative inline SVG, recommended light lines and no background rectangle in both modes.

Evidence: [provenance](http://empytree.com/brand/empytree/v0.3.1/logo-source.json), [manifest](http://empytree.com/brand/empytree/v0.3.1/variants.json), [home](http://empytree.com/), [jugbeat](http://empytree.com/projects/jugbeat), [jugbeat without JS](http://empytree.com/projects/jugbeat?nojs=1).

These checks confirm delivered files and HTML, not every browser's tab UI or an actual Apple device. The browser chooses its ICO layer. The fixed no-JS dark-line fallback does not guarantee contrast on an arbitrary dark tab strip. HTTP availability is verified; HTTPS is outside this record. Private consumer source/history/infrastructure are excluded.

Later overview and documentation changes do not change the deployed package source SHA, version or ZIP. The 0.3.1 package remains pinned to bb58e05; a release tag may include a later documentation snapshot while recording that package source separately.

## По-русски

Прозрачная 0.3.1 внедрена 25 октября 2026. Проверены исходный SHA bb58e05, все 1158 публичных хешей, десять разрешений ICO, главная/jugbeat и no-JS. Home использует светлые линии на прозрачном фоне, выбирается сервером и работает без JS. Рекомендованные цвета #20211f/#f5f4ef не являются строгими константами; творческие изменения задаются явно при известных условиях размещения. В стандартный сайт дополнительные цвета случайно не добавляются. Позднейшее дополнение overview пояснениями не меняет эту версию, геометрию или исходный SHA пакета.
