Public HTTP checks verified the source SHA, all **1158 resource hashes**, the ten resolutions in every delivered ICO, and home/jugbeat with and without explicit `nojs=1`. The normal heads reference both frames; explicit no-JS omits the selector. Jugbeat contains a named home link and a decorative inline SVG in both modes.

Evidence: [provenance](http://empytree.com/brand/empytree/v0.3.0/logo-source.json), [manifest](http://empytree.com/brand/empytree/v0.3.0/variants.json), [home](http://empytree.com/), [jugbeat](http://empytree.com/projects/jugbeat), [jugbeat without JS](http://empytree.com/projects/jugbeat?nojs=1).

This verifies delivered files and HTML, not every browser's tab UI or an actual Apple device. The browser chooses an ICO layer. HTTP availability is confirmed; HTTPS is outside this record. Private consumer history and infrastructure are excluded. Documentation commits do not change the deployed source SHA.

## Subsequent direction

After this rollout the author requested transparent artwork and clarified that `#20211f` / `#f5f4ef` are recommended line colors that may change for creative placement needs. Those changes belong to **0.3.1** and must not overwrite the opaque 0.3.0 URLs or rewrite this adoption record.
