# First website adoption — 0.1.0

Historical first deployment. The current website uses [0.2.1](0.2.1.md); the facts below record the original milestone.

Adopted on 24 October 2026 by the author's personal website, [empytree.com](http://empytree.com/).

- Public source: [7f9c791cf5b261ba5a529a1ce239241a34ac21ce](https://github.com/empytree/logo/commit/7f9c791cf5b261ba5a529a1ce239241a34ac21ce).
- Package: `@empytree/logo` 0.1.0; construction `from-inset` / `character`, micro head scale 0.88 × 0.96.
- Default pool: 24 open-frame expressions, six mouths × four side states.
- Static local resources: `/brand/empytree/v0.1.0/`; one choice per document load; fixed no-JS fallback and Apple icon.
- Scope: shared site templates and independent pages, including the historical static page. Visible English author name is Sergei Parfenov.

The owner confirmed a successful rollout. Independent public HTTP checks confirmed the home page, explicit `?nojs=1` and project page, the published provenance's source commit, and all **29 SHA-256 inventory entries**. The home/project pages reference the selector; the explicit no-JS home page omits it. These checks establish delivered HTML/resources, not an audit of every browser's tab interface.

Public evidence: [provenance](http://empytree.com/brand/empytree/v0.1.0/logo-source.json), [fallback ICO](http://empytree.com/brand/empytree/v0.1.0/favicon.ico), [selector](http://empytree.com/brand/empytree/v0.1.0/random-favicon.js), [no-JS page](http://empytree.com/?nojs=1). The site currently serves HTTP; the owner reports TLS setup is planned. No HTTPS availability is asserted here.
