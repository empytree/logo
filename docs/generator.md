# Генератор, утверждённый micro-набор и компактные знаки

[English](en/generator.md) · [Генератор без сервера](../examples/generator.html) · [Первое внедрение](adoptions/0.1.0.md)

Версия **0.3.1** добавляет прозрачность, два рекомендуемых цвета линий и рисунок до границ холста. Решение автора из 0.2.1 сохраняется: все **288** поддерживаемых micro подходят; общий default — **144** открытых. Последнее подтверждённое [внедрение](adoptions/0.3.0.md) — 0.3.0. [Тема, границы и плотность](themes-and-density.md).

## Независимые параметры

| Параметр | Варианты |
| --- | --- |
| Пара глаз | `arrows`, `beam`, `separate`, `mixed` |
| Рот | `flat`, `rise`, `fall`, `corner-left`, `corner-right`, `down`, `rest8`, `rest4`, `rest2` |
| Бока | `none`, `left`, `right`, `both` с профилем `from-inset` |
| Рамка | `open`, `closed`, `crease`; последняя только display |

`mixed` — короткая вязка у левой ноты и отдельный флажок правой. Половинная пауза стоит над опорной линией. Лица не являются полной исполняемой партитурой. Стык `character` и уменьшенные micro-головки сохраняются.

Реализованы **432** display-выражения и **288** сочетаний compact/micro. Все **288** micro разрешены. Общий пул по умолчанию — **144** открытых; `data-frames="open,closed"` включает все 288. Малый запрос `crease` вызывает ошибку без подмены рамки.

Базовые сетки: micro 16, compact 32, display 64. Каждый ICO имеет десять физических разрешений: 16/20 micro, 24/32/40/48 compact, 64/96/128/256 display. Слои растеризуются из вектора. Расширяется micro-рамка; глаза/рот остаются на пиксельной сетке. Неровные стыки сохраняются, побайтовая совместимость нового рисунка со старым не заявляется.

## Измерения не запрещают использование

Редакция политики **2** записывает `all-supported-variants-approved-by-empytree`. Небольшой зазор, детали четвертной паузы и одинаковый пороговый растр больше не исключают сочетания автоматически.

Рамка, глаза и рот по-прежнему растеризуются отдельно при 1×/2×/3×. Маски включают alpha ≥64/255. Расстояния меньше `density + 1`, мелкие детали и совпадения силуэтов сохраняются как наблюдения вместе с числами. Они не отменяют авторского просмотра.

Прежняя редакция 1 допускала 40 открытых/закрытых, 20 открытых. История решения сохранена в Git и журнале. Сейчас результат — **288 разрешённых, 0 исключённых**, 144 открытых по умолчанию. [Отчёт](research/micro-policy.json), [каталог](../public/brand/v2/variants.json), [реальные пиксели](brand/matrix-micro.png), [крупный лист](brand/matrix-display.png).

## Сборка и отдельный знак

```sh
npm ci
npm run verify
npm run generate -- --eyes mixed --mouth rest4 --dent left --size 16 --format png --output .local/mark.png
npm run generate -- --eyes separate --mouth rest2 --size 32 --output .local/home.svg
```

CLI поддерживает 16–4096 px и SVG/PNG. `--color` задаёт другой явный цвет линий при творческой необходимости; фон остаётся прозрачным. `--theme light|dark` явно выбирает палитру (default light); она входит и в скачиваемый SVG HTML-генератора. SVG без `--output` выводится в stdout; для PNG нужен файл. `--study` сохранён для совместимости, но теперь не обязателен. HTML-генератор содержит все 2016 SVG (1008 оптических рисунков × 2 палитры) и настоящие PNG, открывается с диска без сервера, сети и внешних шрифтов.

## Сайт и хлебные крошки

После коммита владельца, при чистом checkout:

```sh
npm run export:site -- --commit FULL_40_CHARACTER_HEAD_SHA
```

`--development` создаёт preview с null вместо исходного коммита. Пакет 0.3.1 схемы 5 содержит **576 ICO и 576 компактных SVG** в двух палитрах, два fallback ICO, PNG 96/180, selector и manifest — 1158 хешируемых файлов плюс provenance. Каждый ID имеет `ico`/`icoDark`, `svg`/`svgDark`. Проверка старых схем 2/3 сохраняется.

Favicon выбирается один раз при загрузке из указанного набора рамок. Fisher–Yates перемешивает проверяемый sessionStorage-мешок, варианты проходят цикл до повторения, немедленный повтор на границе исключён. Неизвестная/пустая группа сохраняет fallback. Без storage нет гарантии между загрузками. Нет runtime-рисования, загрузки manifest или таймера.

Знак хлебных крошек может независимо выбираться сервером из `markPool`, включая режим без JavaScript. Разрешены только SVG из manifest внутри каталога зафиксированного пакета. Доверенный SVG вставляется inline с рекомендованным цветом линий и прозрачным фоном. Для тёмной шапки выбирать `svgDark`; цвет ссылки не меняет знак. Ссылка получает доступное имя «Home», вложенный SVG — `aria-hidden="true"`, `focusable="false"`. Размер около 32–40 CSS px подходит компактным крошкам; предусмотреть удобную область нажатия, видимый focus и отсутствие сдвига после загрузки.

Потребитель сохраняет версионные локальные URL и `logo-source.json`. Development-пакет не считается выпуском. Запись внедрения создаётся после реальной выкладки. Общий контракт и поведение первой версии — в [usage](en/usage.md).

Изменение `prefers-color-scheme` переключает только палитру выбранного favicon, без нового случайного выбора или расхода мешка.
