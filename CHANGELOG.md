# Changelog

## 0.2.0 — release candidate

- Independent four-eye-pair / nine-mouth generator: 432 display expressions, 288 compact and 288 micro candidates.
- Explicit micro policy at 1x/2x/3x: 40 eligible open/closed choices, 20 open-frame defaults; 248 excluded.
- Full offline generator, CLI SVG/PNG export, native-pixel contact sheets and machine-readable rejection reasons.
- Allowlist-based selector and next website package. Original approved geometry remains unchanged.
- English/Russian generator documentation and a factual first-adoption record.

This candidate is not yet adopted on the website.

## 0.1.0 — published and adopted on 2026-10-24

Public source and HTTP verification are recorded in [the adoption record](docs/adoptions/0.1.0.md).

- Accepted intermediate shallow side profile and irregular note joints.
- Six mouths, four side states, separate display/compact/micro geometry.
- Smaller micro noteheads to improve the left-side gap.
- Limited 24-choice website pool and optional closed-frame source variants.
- Standalone examples, English entry documentation and Russian detailed research/history.
- Versioned consumer package with source-commit and checksum provenance.
- At this milestone the full musical generator and size-specific exclusions were still planned.

The design history is summarized in [development-history.md](docs/development-history.md); commit grouping is described in [commit-plan.md](docs/commit-plan.md).
